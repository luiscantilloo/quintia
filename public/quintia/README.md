# Activos de marca QUINTIA

Los SVG en `logo/`, `tejiva/` y `favicon.svg` son los logos oficiales del producto (pack de branding actual).

- **Logo horizontal / wordmark:** `logo/quintia-horizontal-*.svg`, `quintia-wordmark-*.svg`
- **Isotipo:** `logo/quintia-fuerzas.svg`
- **TEJIVA:** `tejiva/tejiva-*.svg`
- **Favicon:** `favicon.svg`
- **Iconos de herramientas UI:** `herramientas/*` (PNG/SVG de módulos)

La app consume estas rutas vía `src/lib/brand.ts` (`/quintia/...`).
